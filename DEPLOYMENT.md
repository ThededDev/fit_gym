# Развертывание проекта на TatNet.ru

## Обзор проекта

FitGym - это фитнес-приложение с:
- Frontend: React + Vite + TypeScript
- Backend: Node.js + Supabase SDK
- Database: Supabase PostgreSQL
- Styling: Tailwind CSS

## Подготовка к развертыванию

### 1. Требования к репозиторию

Проект уже подготовлен для развертывания на TatNet.ru:
- ✅ Добавлен `Procfile` для запуска Node.js сервера
- ✅ Добавлен `.nvmrc` для указания версии Node.js (18)
- ✅ Обновлен `.gitignore` для исключения чувствительных файлов
- ✅ Добавлен скрипт `start` в `package.json`
- ✅ Обновлен `.env.example` с переменными окружения

### 2. Настройка базы данных

1. Убедитесь, что проект Supabase создан на [supabase.com](https://supabase.com)
2. Получите следующие данные из настроек проекта:
   - Project URL
   - anon public key
   - service_role key (для серверной части)
3. Выполните миграции базы данных используя файлы:
   - `db/schema.sql` - структура базы данных
   - `db/seed.sql` - тестовые данные

### 3. Переменные окружения

На TatNet.ru настройте следующие переменные окружения:

```bash
# Supabase SDK
SUPABASE_URL=https://kptoweyhevaasfdbwbbs.supabase.co
SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key

# Сервер
PORT=8787
NODE_ENV=production
```

## Процесс развертывания

### Шаг 1: Подключение Git-репозитория

1. Убедитесь, что код находится в Git-репозитории
2. Добавьте изменения и запушите в удаленный репозиторий:
   ```bash
   git add .
   git commit -m "Готово к развертыванию"
   git push origin main
   ```

### Шаг 2: Создание приложения на TatNet.ru

1. Войдите в панель управления TatNet.ru
2. Создайте новое приложение
3. Выберите тип приложения: Node.js
4. Подключите ваш Git-репозиторий
5. Укажите ветку для развертывания (обычно `main`)

### Шаг 3: Настройка окружения

1. В настройках приложения добавьте переменные окружения (см. выше)
2. Убедитесь, что версия Node.js соответствует 18 (из файла `.nvmrc`)

### Шаг 4: Развертывание

1. Запустите процесс развертывания
2. TatNet.ru автоматически:
   - Установит зависимости (`npm install --production`)
   - Выполнит сборку (если есть скрипт `build`)
   - Запустит приложение через Procfile (`node server/index.mjs`)
3. Дождитесь завершения развертывания

### Шаг 5: Проверка

1. После успешного развертывания вы получите URL приложения
2. Проверьте работоспособность:
   - Откройте главную страницу
   - Проверьте API endpoints (должен быть доступен `/api/health`)
   - Протестируйте авторизацию

## Устранение проблем

### Приложение не запускается

1. Проверьте логи в панели TatNet.ru
2. Убедитесь, что все переменные окружения настроены правильно
3. Проверьте подключение к базе данных

### Ошибки базы данных

1. Убедитесь, что миграции выполнены
2. Проверьте строку подключения к базе данных
3. Проверьте права доступа пользователя базы данных

### Проблемы с сборкой

1. Убедитесь, что все зависимости указаны в `package.json`
2. Проверьте версию Node.js
3. Проверьте наличие скрипта `build` (если нужен)

## Локальная разработка

Для локальной разработки:

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Запуск только API
npm run dev:api

# Запуск только frontend
npm run dev:web

# Сборка для production
npm run build

# Запуск в production режиме
npm start
```

## Дополнительная информация

- Структура API: сервер запускается на порту 8787
- Frontend: собранные файлы обслуживаются через Vite
- Database: используется Supabase SDK для работы с PostgreSQL
- Аутентификация: реализована через custom JWT с Supabase (см. `api/_supabase.js`)
